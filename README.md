# 🔁 Palindrome Checker (JavaScript)

This repository contains simple **JavaScript programs** to check whether a word is a palindrome or not.  
I have implemented **multiple approaches** for learning purposes:

## 📌 Methods Covered
1. **Character by Character Comparison**  
   - Example: `stairs`, `madam`, `civic`
2. **Reverse & Compare Method**  
   - Example: `meelad`
